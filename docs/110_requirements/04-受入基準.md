# 受入基準

> 作業記録アプリのサンプルです。新しい製品では、最初のIssueへ着手する前に本文を削除し、実際のシナリオで要求を満たしたと判定できる状態を書き直してください。

## AC-001: HTTPから作業を始めて保存結果を受け取れる [REQ-001] [SC-001]

`POST /activities` へ `{"title":" 設計を書く "}` を送ると、応答状態201と、識別子、`設計を書く`、開始時刻を返し、SQLAlchemyを通してSQLiteへ一件保存する。空の作業名は応答状態422と理由を返し、保存しない。

## AC-002: Goクライアントから同じ作業開始を使える [REQ-002] [SC-002]

GoのCLIへ `start "設計を書く"` を渡すと、公開HTTP契約でバックエンドへ要求し、`開始: 設計を書く` と表示する。バックエンドではSQLAlchemyを通して一件保存される。Go側はバックエンドのPythonコードを読み込まない。
