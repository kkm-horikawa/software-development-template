# 利用者とシナリオ

> 作業記録アプリのサンプルです。新しい製品では、最初のIssueへ着手する前に利用者とシナリオ一覧を削除し、実際の利用者の目的から書き直してください。

## 関係する立場

| 立場 | 目的 |
|---|---|
| 作業を記録する人 | 作業を始めた時点で内容と時刻を残し、あとから実績を追う |
| クライアントを作る開発者 | バックエンドの言語と内部構造を知らず、公開契約から別の利用先を作る |
| 保守する開発者 | 利用の流れと保存の境界を壊さずに機能を変更する |

一人が複数の立場を兼ねることがあります。製品を操作する立場と、コードを保守する立場は分けて考えます。
