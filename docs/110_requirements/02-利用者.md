# 利用者

> 作業記録アプリのサンプルです。新しい製品では、最初のIssueへ着手する前に本文を削除し、実際の利用者の立場と目的から書き直してください。現在のシナリオ一覧は[シナリオ](シナリオ/README.md)へ分けます。

## 利用者の立場と目的

| 立場 | 目的 |
|---|---|
| 作業を記録する人 | 作業を始めた時点で内容と時刻を残し、あとから実績を追う |
| 新しい入口を提供する開発者 | 既存の利用体験を壊さず、利用者の場面に合う別の入口を提供する |
| 保守する開発者 | 利用の流れと保存の境界を壊さずに機能を変更する |

一人が複数の立場を兼ねることがあります。製品を操作する立場と、コードを保守する立場は分けて考えます。
