# SC-001: 作業を始める [PB-001]

## 目的

作業を記録する人が、着手した時点で作業名と開始時刻を残し、あとから何を始めたか追えるようにする。

## きっかけ

作業を記録する人が、新しい作業へ着手する。

## 中心の流れ

1. 作業を記録する人が、HTTPの入口へ作業名を渡す。
2. システムが前後の空白を除き、空でない作業名か確かめる。
3. システムが識別子と開始時刻を決め、作業を保存する。
4. システムが識別子、整えた作業名、開始時刻を返す。
5. 作業を記録する人は、記録が残ったと判断して作業を続ける。

## うまく進めない場合

- 作業名が空なら、理由を返して何も保存しない。
- 保存に失敗したら成功したように返さない。

## 現在の範囲

作業の一覧、終了、修正、認証はこのサンプルでは提供しない。

システムでの処理順は[SC-001 作業を始めるシーケンス](../../150_system/シーケンス/SC-001-作業を始める.md)で確認できます。
