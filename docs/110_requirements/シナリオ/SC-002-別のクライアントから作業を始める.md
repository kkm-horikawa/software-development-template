# SC-002: 別のクライアントから作業を始める [PB-002]

## 目的

クライアントを作る開発者が、バックエンドのPythonコードを使わず、公開された通信の約束だけから利用先を追加できるようにする。

## きっかけ

作業を記録する人が、Goで作られたCLIから作業を始める。

## 中心の流れ

1. 作業を記録する人が、CLIへ `start` と作業名を渡す。
2. CLIが作業名を整え、公開されたHTTPの要求へ変える。
3. バックエンドが作業を保存し、公開契約どおりの応答を返す。
4. CLIが応答を読み、開始した作業名を表示する。
5. 作業を記録する人は、利用先が違っても同じ作業が残ったと判断できる。

## うまく進めない場合

- バックエンドへ到達できない、または契約外の応答なら、CLIは失敗を返す。
- CLIの入力が空なら、バックエンドを呼ばず理由を返す。

## 現在の範囲
